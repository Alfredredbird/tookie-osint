What V4 does

Version 4 was rewritten from scratch for speed. Pick a username, and Tookie-OSINT does the legwork.

Username discovery

Searches site by site and reports a hit when the account exists. Accurate roughly 80% of the time, and improving.

Threaded and fast

Runs many checks in parallel, so long site lists don't mean long waits.

Scripting and automation

Run it headless, chain it in your own scripts, and export results to CSV.

Tor searching

Route lookups through Tor when you need the request to stay off your own address.

Webscraper

Pull public data from the profiles it discovers.

Restore files

Interrupted scan? Pick up where it stopped instead of starting over.

Webhooks beta

Send results to your own endpoint as they arrive.

Easy to read

Plain Python and a simple UI, written so new programmers can follow it and contribute.

Install

Requirements install automatically. Tookie-OSINT is tuned for Python 3.12.

sudo apt install tookie-osint
git clone https://github.com/alfredredbird/tookie-osint.git cd tookie-osint chmod +x install.sh sudo ./install.sh
# download tookie-osint.deb from the releases page, then: sudo dpkg -i tookie-osint.deb
git clone https://github.com/alfredredbird/tookie-osint cd tookie-osint python3 -m venv venv source venv/bin/activate pip3 install -r requirements.txt python3 brib.py

Run -h any time for the full option list. More guides are on the wiki.
